# ShopMaster — админ-панель интернет-магазина

Панель, в которой менеджер управляет товарами, заказами, клиентами и смотрит аналитику продаж.

**Демо:** https://shopmaster-bdccc.web.app (вход только для менеджеров, аккаунты создаются в Firebase Console)

## Возможности

- **Дашборд** — ключевые показатели с мини-графиками, график продаж с прошлым периодом, последние заказы, популярные товары, остатки, лента активности.
- **Товары** — добавление, редактирование и удаление, поиск, фильтр по категории, сортировка, изменение остатка, фото, массовое скрытие и удаление.
- **Заказы** — ручное создание со списанием остатков, смена статуса (с возвратом товара на склад при отмене), история статусов, массовая смена статуса, печать накладной.
- **Клиенты** — список и карточка клиента: показатели, история заказов, любимые товары.
- **Аналитика** — периоды от 7 дней до всего времени, доход и заказы, статусы, категории, тепловая карта «когда покупают», топ-10 товаров, отчёт в CSV.
- **Настройки** — валюта, порог низкого остатка, категории, демо-данные.
- Глобальный поиск по **Ctrl+K**, уведомления о новых заказах и низких остатках.
- Тёмная и светлая тема, 4 языка интерфейса: українська, русский, English, slovenčina.

## Технологии

Angular 22 (standalone, signals, zoneless, Signal Forms), Angular Material 3, Chart.js, Firebase Auth и Firestore, Vitest.

## Запуск

```bash
npm install
npx ng serve        # http://localhost:4200
npx ng test         # unit-тесты
npx ng build        # сборка в dist/ShopMaster/browser
```

Конфигурация Firebase — `src/app/core/firebase-config.ts`. Правила доступа к Firestore — `firestore.rules`: читать и писать могут только вошедшие пользователи.

## Публикация

```bash
npx ng build
npx firebase-tools deploy --only hosting
```
